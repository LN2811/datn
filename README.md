# datn

Lenh chay da duoc rut gon o thu muc goc.

Trong PowerShell:

```powershell
.\dev
.\fe
.\be
```

`.\dev` se mo backend bang PowerShell rieng va chay frontend trong terminal hien tai.

Neu muon dung npm script thi goi bang `npm.cmd` de tranh loi execution policy:

```powershell
npm.cmd run dev
npm.cmd run fe
npm.cmd run be
```

Mot so alias khac:

```powershell
.\stack
.\db
```
